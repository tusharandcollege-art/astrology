ℹ️ How It Works
Simple guide to using the admin panel

1. Edit Content — Click any section in the left menu to edit that part of the website.

2. Save Changes — Click the "Save Changes" button to apply your edits. The website will update instantly.

3. Preview — Click "Preview Site" to see the live website with your changes.

4. Leads & Bookings — All form submissions and bookings appear in the Data section of the sidebar.

⚠️ Note: Changes are saved in this browser. To update the live Vercel site, the developer needs to push changes to GitHub.
